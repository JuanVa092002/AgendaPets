## 📋 Descripción

Plataforma web para la gestión de reservas de servicios de **pet grooming**, diseñada para optimizar procesos, mejorar la experiencia del usuario y garantizar el bienestar de las mascotas. Incluye panel de administrador funcional con historial de servicios.

---

### Frontend

| Tecnología | Descripción |

| JavaScript | Lenguaje principal del frontend |
| HTML5 | Estructura de las páginas |
| CSS3 | Estilos y diseño responsive |

## ✅ Funcionalidades Implementadas

### 🔐 Autenticación
- Registro de usuarios (ADMIN / CLIENTE)
- Inicio de sesión con autenticación JWT
- Protección de rutas por roles

### 🐕 Gestión de Mascotas
- Registrar mascotas asociadas a un cliente
- Editar información de mascotas
- Eliminar mascotas

### 💇 Servicios
- Catálogo de servicios de peluquería
- Precios y duraciones configurables
- Administración completa del catálogo

### 📅 Reservas
- Crear reservas de servicios para mascotas
- Seguimiento de estados de la reserva
- Gestión completa del ciclo de reserva

### 🔍 Consultas
- Búsqueda por correo
- Búsqueda por usuario
- Búsqueda por fecha
- Búsqueda por estado

### 📊 Panel de Administrador
- Gestión completa del sistema
- Historial de servicios
- Supervisión de reservas y clientes
